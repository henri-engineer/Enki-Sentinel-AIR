# Enki-Sentinel-AIR
Monitor ENKI Sentinel AIR foi concebido como uma solução IoT avançada para monitoramento, análise e reação automática à qualidade do ar em ambientes residenciais, industriais e estratégicos. Em um cenário global onde o aumento de CO e CO₂ se tornou um desafio ambiental crítico, o projeto propõe uma abordagem técnica, integrada para promover saúde.
